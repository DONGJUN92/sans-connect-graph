# 🌟 SANS Connect — 산스(SANS) 연결의 힘 인터랙티브 지식그래프

발표 전후로 산스(SANS) 구성원들이 **‘연결의 힘’**을 시각적으로 체험할 수 있도록 제작된 실시간 인터랙티브 지식그래프 웹앱입니다.

## ✨ 주요 기능

1. **산스(SANS) 중심 전체 지식그래프 & 클럽별 지식그래프 전환**
   - **산스 전체 뷰**: 중심 허브 `산스(SANS)`를 기준으로 **16개 클럽**과 모든 구성원이 어떻게 엮여 있는지 한눈에 보여줍니다.
   - **클럽 중심 지식그래프**: 16개 클럽(멘토링, 스피치, AI, 골프, 논어, 댄스, 러닝, 바이오, 부동산, 연극, 영화, 중급 영어 북클럽, 초급 영어 북클럽, 태극권, English Speech, Sans 레가타) 중 하나를 선택하면 해당 클럽이 중앙에 배치되고 소속 멤버와 교차 활동 클럽·조·키워드 관계도가 펼쳐집니다.
   - **조별(1조~20조) 지식그래프**: `1조`부터 `20조`까지 특정 조를 선택하면 해당 조 구성원들을 중심으로 연결망을 보여줍니다.
2. **특정 이름 선택 시 가독성 높은 연결선 시각화 (`허브 뷰` & `1:1 직통 연결선 뷰`)**
   - 상단 **이름 검색창**이나 빠른 선택 칩에서 특정 구성원(예: `신동준`)을 선택하면, 그 구성원을 정중앙에 두고 연결된 **클럽·조·공감 키워드 및 동료들**이 겹침 없이 선명한 연결선으로 표시됩니다.
   - **`클럽·조·키워드 허브 뷰`**와 **`1:1 직통 연결선 뷰`**를 버튼 하나로 전환할 수 있습니다.
3. **100% 선택형 키워드 & 간편 등록 (`동료 직접 지목 불필요`)**
   - 참가자는 스마트폰 QR 스캔 후 **`이름` → `소속 조(1조~20조)` → `소속 클럽(16개 중 복수 선택)` → `공감 키워드(6개 카테고리 48개 후보 중 탭하여 선택)`**만 고르면 즉시 그래프에 실시간 반영됩니다.
4. **스마트폰 QR 동시 접속 실시간 동기화**
   - 우측 상단 **`[QR 참여]`** 버튼을 눌러 화면에 QR 코드를 띄우면, 청중이 스마트폰으로 스캔하여 등록할 때마다 발표 스크린과 모든 참가자 화면에 실시간으로 노드가 추가됩니다.

## 🚀 로컬 실행 및 Vercel 배포 방법

```bash
npm install
npm run dev
```

### Vercel 배포
1. [Vercel Dashboard](https://vercel.com/new)에서 이 GitHub 저장소(`sans-connect-graph`)를 **Import**합니다.
2. 별도의 환경변수 설정 없이 바로 **Deploy** 버튼을 누르면 즉시 배포가 완료됩니다.
